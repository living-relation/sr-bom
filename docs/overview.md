# Overview

SR BOM is a Spark Robotic add-in for Autodesk Fusion. It fills bill-of-materials (BOM) fields on a design and exports that data to CSV and Excel.

It is part of the Spark Robotic (SR-) tool set for Fusion.

## What this repository is today

This repository currently holds documentation, a license, and a Python `.gitignore`. The add-in code has not been added yet. Feature-specific behavior in these docs is marked as to be completed when the code lands.

## Features

- Fill BOM fields on the active Fusion design.
- Export BOM data to CSV.
- Export BOM data to Excel.

The exact BOM fields, export options, and command layout are to be completed when the code lands.

## Requirements

- Autodesk Fusion

No other requirements are documented yet. Runtime dependencies, if any, are to be completed when the code lands.

## Status

The add-in will be added in a follow-up pull request. Until then, treat this repository as the public home and documentation for **SR BOM**.
